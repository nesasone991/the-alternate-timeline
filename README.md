# The Alternate Timeline

*History happened once. What if it didn't?*
An interactive historical experience by **Tales of the Past**.

Explore documented history, change a pivotal decision and compare the two timelines. The first campaign is **The Fall of Rome (c. 455–476 AD)**.

> **Status: private beta prepared (0.9.0-beta.1), not deployed.** The sourced historical timeline, all five alternate-history decisions on a tested deterministic engine, three endings with a full ending experience, saves, a labelled beta build for Cloudflare Pages, optional privacy-conscious usage counts and a beta questionnaire are in place. The map, comparison, share card and Creator Mode are not built yet and are labelled as such in the app. See [docs/PROJECT_STATE.md](docs/PROJECT_STATE.md).

![CI](https://github.com/nesasone991/the-alternate-timeline/actions/workflows/ci.yml/badge.svg)

## Requirements

- Node.js **20.19 or newer** (22 LTS recommended) and npm.
- No accounts, API keys or paid services.

## Getting started

```bash
npm ci               # install the exact versions in package-lock.json
npm run dev          # start the dev server at http://localhost:5173
```

## Commands

| Command | What it does |
| --- | --- |
| `npm run dev` | Development server with hot reload |
| `npm run build` | Type-check, then build the static site into `dist/` |
| `npm run preview` | Serve the production build locally at http://localhost:4173 |
| `npm run typecheck` | TypeScript only |
| `npm run lint` | ESLint |
| `npm test` | Unit and component tests (Vitest + Testing Library, jsdom) |
| `npm run check` | Typecheck, lint, tests, build and the deployment check — run before every commit |
| `npm run check:dist` | Deployment check of `dist/` (Cloudflare Pages routing rules, headers, robots, secrets, size budget) |
| `npm run test:e2e` | Playwright end-to-end tests against the production build (run `npm run build` and `npx playwright install chromium` first) |

CI (GitHub Actions) runs install, typecheck, lint, unit and component tests, build, the deployment check, Playwright end-to-end tests (desktop and mobile) and the deployment tests against Cloudflare's local Pages emulator on every push to `main`.

## Project layout

```
src/
  app/            routes, layout shell, error boundary
  pages/          one component per route
  components/     shared UI: layout (header, footer) and primitives (icons, badges)
  features/       campaigns, history (timeline), settings, workspace, home
  data/           campaign catalog and per-campaign content (scenarios/rome)
  types/          contracts: history, campaign, simulation, map, creator
  lib/            dates, catalog lookups, validation, small hooks
  config/         brand constants and channel links
  styles/         Tailwind entry and design tokens
public/           favicon (_headers and robots.txt are generated by the build)
scripts/          release configuration and the deployment check
tests/            unit/ (pure logic and data) and components/ (rendered UI)
docs/             architecture, scope, history review, QA, deployment, state
```
