# Demo checklist and capture guide (Tales of the Past)

Creator Mode (clean playback, 9:16 / 16:9 safe frames, bookmarks) is **not built yet** — it is Phase 5. Until then you can still record honest footage of the real-history timeline.

## Two-minute demo checklist

1. Home page: the title, the forking-timeline diagram drawing in (needs motion and ambient animation on).
2. **Explore History** → the Fall of Rome card, then the Napoleon and Viking Age cards showing "Not yet available".
3. **Explore campaign** → overview: introduction, "Rome did not end in 476", the dated events with sources and caveats.
4. **Open the workspace** → press **Play** at 1× and let the timeline run from 455 to 480; stop on 476 to show the caveat and the Eastern Empire note.
5. Click the **Alternate History** tab to show that it is clearly marked as not built.
6. Open **Settings** and switch year notation between AD and CE.

## Recording now (Phase 1)

1. Use OBS Studio (free) with a *Window Capture* of the browser, or the browser's own screen recorder.
2. Browser window: 1920×1080 for horizontal video. For vertical video, open developer tools' device mode at 1080×1920 (or 540×960 and scale ×2) — the layout is fully responsive.
3. Hide the cursor in OBS and close other tabs and notifications.
4. In Settings choose *Always allow motion* for playback footage, or *Always reduce motion* for still shots.
5. Workspace playback speed: 0.5× for narration, 1× for montage, 2× for a fast sweep.
6. Label every shot in the edit: footage from the workspace in Real History mode is **sourced history**; anything from Alternate History (once built) must be captioned **fictional alternate history**.

## Video recipes (from the Blueprint, usable once gameplay exists)

- **Historical fact short (30–45 s):** hook → real timeline/event → concise context → the decision point → invitation to explore.
- **Counterfactual short (30–45 s):** hook → decision → consequences → unexpected trade-off → result → call to action. Requires Phase 2.
- **Long video (5–10 min):** sourced baseline → objectives → decisions → consequences → comparison → limitations → call to action. Requires Phases 2–4.
